Adjudicate a disputed milestone

Anyone can trigger adjudication once a milestone is disputed. Validators read the deliverable and the evidence, then classify every acceptance criterion as met, unmet, or unclear. The settlement — release, refund, or split — is derived in code from those classifications, never chosen by the model.

Track record

Every settled milestone is counted per address, so a client can see how a freelancer's milestones have been resolved and vice versa.

EscrowCourt keeps an on-chain settlement ledger and track record. It does not move real value.
